# q-term

Fast, sleek multi-platform terminal (Mac-first) built with Wails (Go + React/TS).

- Project / Home / Quick terminal sidebar
- Split/grid multi-pane terminals
- Tailwind + shadcn/ui, Qortex state
- Installable agent hooks

## Develop

```bash
wails dev
```

## Build

```bash
wails build
```
